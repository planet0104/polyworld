## 开源代码库（完整实现）

**官方仓库（推荐）：**

- **GitHub**: [github.com/polyworld/polyworld](https://github.com/polyworld/polyworld)
- 原托管在 [SourceForge](http://sourceforge.net/projects/polyworld)，2015 年起迁到 GitHub

- 许可：Apple Public Source License (APSL)

克隆与运行示例：


## 「完整实现」到什么程度？

按作者说明，**核心仿真引擎是完整可用的**，包含论文中的主要机制：

- 遗传编码的神经网络（拓扑、簇大小、连接密度等由基因组决定）
- Hebbian 学习
- 基于 OpenGL 的视觉感知（第一人称渲染）
- 代谢、繁殖、捕食、觅食等生态交互
- **Sporns 神经复杂度度量**（Virgil Griffith 实现的简化 TSE complexity，C++）
- **driven vs passive** 对照实验（验证自然选择驱动的复杂度上升）
- 小世界网络拓扑分析（bct-cpp）
- Izhikevich 脉冲神经元模型（后期扩展）
- FoodPatches 等资源补丁机制

作者曾提到约 90% 旧版 UI 功能已恢复，**剩余主要是界面细节，不影响核心演化仿真**。

## 和你关心的「神经复杂度趋势」的关系

Yaeger & Sporns (2006) 及后续 HFSP / ALife XI / XII 论文中的复杂度分析，**都基于这套开源 Polyworld + 内置复杂度计算工具**：

1. 仿真中记录每个 agent 全生命周期的神经激活
2. 用 C++ 实现的简化 TSE complexity 计算 \(C\)
3. 对比 driven（有自然选择压力）与 passive（零选择压力）种群

因此：**不是只有论文概念，而是有可运行、可复现的完整系统**。
